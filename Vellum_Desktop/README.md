**Author: Amine Zouaghi (amine.zouaghi@unipr.it) | University of Parma & University of Bologna**

This directory contains the complete source code and environment for the **Vellum Desktop Workbench**.

---

## 📁 What's in this folder

| Item | What it is |
| :--- | :--- |
| **`launch_desktop_app.bat`** | One-click launcher to run the desktop workbench from source |
| **`Desktop_App\`** | Python 3.13 application source code, Pytest suite, and spec configs |
| **`README_VELLUM_DESKTOP_V2.1.pdf`** | Publication-grade offline manual |

---

## 🚀 Quick Start

### 1. Run from Source
Double-click **`launch_desktop_app.bat`**.
The launcher auto-detects the local virtual environment and launches `http://localhost:8501` in your browser.

### 2. Standalone Windows Installer
Pre-compiled standalone installers (`.exe`) and zero-install portable bundles are hosted under [GitHub Releases](https://github.com/aminezghi/vellum/releases/latest) and in `DISTRIBUTABLES/`.
