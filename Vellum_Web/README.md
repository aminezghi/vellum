# Vellum Web — Academic Research Studio
**Author & Lead Architect: Amine Zouaghi (amine.zouaghi@unipr.it) | University of Parma & University of Bologna**  
*Next.js 16 (Turbopack) / React 19 / Tailwind CSS 4 • Node.js 18+*  
*Host & Port: `http://localhost:3002`*

This directory contains the complete source code and environment for the **Vellum Web Studio**.

---

## 📁 What's in this folder

| Item | What it is |
| :--- | :--- |
| **`launch_web_app.bat`** | One-click launcher to run the web studio from source |
| **`Web_App\`** | Next.js 16 source code, components, API routes, and test suite |
| **`Web_App\README_FOR_COLLEAGUES.md`** | Standalone web manual |

---

## 🚀 Quick Start

### 1. Run from Source
Double-click **`launch_web_app.bat`** (or run `npm run dev` / `npm run build` inside `Web_App\`).
The launcher boots the studio on `http://localhost:3002`.

### 2. Zero-Install Colleague Share Package
If sharing with colleagues who do not have Node.js installed, use the pre-built **`Vellum_Web_Fernly_OneClick_Package.zip`** from [GitHub Releases](https://github.com/aminezghi/vellum/releases/latest) or `DISTRIBUTABLES/`, which bundles its own verified portable Node.js runtime.
