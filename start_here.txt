Welcome! This pack contains 2 applications, in 2 separate folders.
Everything runs locally on your machine - no account, no cloud,
no telemetry.

    Vellum_Desktop\   the desktop workbench      (port 8501)
    Vellum_Web\       the browser research studio(port 3002)

Neither folder depends on the other - use either one on its own.

1. TO INSTALL VELLUM DESKTOP V2.0 (RECOMMENDED):
   -> Double-click: Vellum_Desktop\Vellum-Desktop-V2.0-Setup-x64.exe
   (Standard Windows installer. No admin rights needed. Adds a Start
    Menu entry and a proper uninstaller. No Python required.)

2. TO TRY THE DESKTOP WORKBENCH WITHOUT INSTALLING:
   -> Double-click: Vellum_Desktop\1_launch_desktop_app.bat
   (Runs from source using the bundled virtual environment.
    Opens at http://localhost:8501)

3. TO TRY THE WEB RESEARCH STUDIO:
   -> Double-click: Vellum_Web\2_launch_fernly_web_app.bat
   (Requires Node.js 18+. Opens at http://localhost:3002)

4. TO RUN BOTH AT THE SAME TIME:
   -> Double-click: 3_launch_both_apps.bat
   (Desktop on 8501 + Web on 3002, side by side)
