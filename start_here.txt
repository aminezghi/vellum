Welcome! This pack contains 2 applications, in 2 separate folders.
Everything runs locally on your machine - no account, no cloud,
no telemetry.

    Vellum_Desktop\   the desktop workbench      (port 8501)
    Vellum_Web\       the browser research studio(port 3002)

Neither folder depends on the other - use either one on its own.

1. TO INSTALL VELLUM DESKTOP (RECOMMENDED):
   -> Double-click: Vellum-Desktop-Setup-x64.exe (from GitHub Releases)
   (Standard Windows installer. No admin rights needed. Adds a Start
    Menu entry and a proper uninstaller. No Python required.)

   NOTE: Windows may say "Windows protected your PC" on first run because
   the installer is not code-signed. Click: More info -> Run anyway.
   To check the file integrity, compare with DISTRIBUTABLES\SHA256SUMS.txt.

2. TO TRY THE DESKTOP WORKBENCH:
   -> Double-click: launch_desktop.bat (or Vellum_Desktop\launch_desktop_app.bat)
   (Runs using the bundled virtual environment.
    Opens at http://localhost:8501)

3. TO TRY THE WEB RESEARCH STUDIO:
   -> Double-click: launch_web.bat (or Vellum_Web\launch_web_app.bat)
   (Runs Next.js web studio. Opens at http://localhost:3002)

4. TO RUN BOTH AT THE SAME TIME:
   -> Double-click: launch_both.bat
   (Desktop on 8501 + Web on 3002, side by side)
